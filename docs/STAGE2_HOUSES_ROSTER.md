# Stage 2+: haunted houses, roster, special attacks, gear (what is real, what is verified)

## Haunted houses (HOUSE_01 .. HOUSE_30)
`world/Houses.java` (framework + 01-05) and `world/HousesB.java` (06-30). Every house has its own hand-written design and four Sign texts in English
(waxed, so players cannot edit them); each has a `lore_desk` (feeds the existing notes) and a chest. The seven usernames appear exactly as written.
Placement (`Houses.place`): never over player-made blocks (`Structures.isClear`), no water/ocean/river, terrain spread <= 3, >= 40 blocks from any recorded
structure and >= 160 from another house, each house once per dimension, recorded in `StructureData` (so `/lastsignal locate HOUSE_nn` works).
Event `env_haunted_house` (rare; config `hauntedHouseFrequency`, 0 disables): houses unlock with the story stage (6 per stage); HOUSE_30 only after HOUSE_29 exists.
Progression chain: HOUSE_29 (Last Camp) holds the `red_key`; HOUSE_30's entrance is a `sealed_door_block` that opens with it. `/lastsignal place HOUSE_nn` places one in front of an operator.
## Roster
17 original horrors + 12 new (Black Witness, Tall Black ~3 m, Borrowed Skin, Drowned Choir, Hanging Man, Salt Mother, Radio Shepherd, Glass Walker, Candle Bearer,
Paper Man, Stair Thing, Moon Watcher) + White Presence = 30. New ones have GeckoLib rigs (bones/animations generated by tools/monsters.py), behaviours by archetype, spawn eggs,
and 12 stage-gated events. `tools/generate_assets.py` must NOT be re-run in full (it regenerates all dimension sounds/textures and overwrites sounds.json/lang);
the new assets were kept and everything else restored.
## Special attacks
`entity/SpecialAttacks.java`: 14 moves (lunge, ankle grab, tremor slam, step behind, shatter, pull down, wide bite, choir wail, echo cry, stare, black stare, snuff, salt wall, dread).
Cooldown, range band, minimum story stage, 1-in-3 roll, line of sight; status effects/impulses/small damage only; no block changes; config `enableSpecialAttacks`.
## Gear
Lantern Warden armor (full set: Darkness immunity, -15% damage from creatures), Salt Iron Sword (frightens), Echo Dagger (backstab bonus), Signal Halberd (bonus vs creatures); recipes in data, assets via tools/gear.py.
## Volcano
All hostile spawners removed from the biome and the spawn-rule code deleted (CI asserts no spawners in any category). Added: charred statue groups along the road, tremors, lava geysers, whispers/breathing/knocks, ash storm.
## Verified by CI (compile + headless server)
dimensions=50 failures=0; 30 houses built in a test world, 120 signs found, 29 horror profiles instantiated and ticked, 14 special attacks executed, volcano has no spawners.
